# Terralyt

Geospatial intelligence platform for Pakistani housing societies. FAST-NUCES (Chiniot-Faisalabad) Final Year Project, 2026.
Team: Taha Saleem Sheikh (23F-0517), Muhammad Mursaleen Mustafvi (23F-0659), Rahmeen Nasr (23F-0700). Supervisor: Ms. Mahzaib Younas.

Terralyt shows a housing society as an interactive 3D map, rates its development Low / Medium / High from satellite data, and gives a 5-year forecast. Users: buyers, investors and overseas Pakistanis who cannot visit the society. Pilot society: **FDA City, Faisalabad** (OSM centre 31.525 N, 73.088 E, next to the M-3/M-4 motorways).

- **Taha:** 3D map (`map.html`, `assets/map3d.js`, `data/`, `tools/`) and the AI/ML development model.

## Repo layout

- `*.html` + `assets/app.js` + `assets/style.css`: the UI. **Plain HTML, CSS and JavaScript, not React.** No `package.json`, no npm, no build step.
- `assets/app.js`: shared helpers and sample `PLOTS` (60 plots) used by `plot.html`, `search.html` and the top search bar. `badge()` and `qs()` are used by every page.
- `assets/iso.js`: the old drawn (SVG) demo map; still used by `plot.html`.
- `map.html` + `assets/map3d.js`: the CesiumJS 3D map.
- `data/*.geojson`: map data, generated by `tools/make_data.py` from `tools/source/osm_fda_city.json` (OpenStreetMap export).
- `tools/shoot.py`: headless-browser screenshot of the map for visual checks (Playwright, uses installed Chrome).

## Run locally

1. Copy `assets/config.example.js` to `assets/config.js` and paste a Cesium ion token. `config.js` is git-ignored; never commit it. Without a token the map runs on OpenStreetMap tiles and flat ground.
2. `python -m http.server 8000` in the repo root (opening files directly breaks `fetch` of the GeoJSON).
3. Open `http://localhost:8000/map.html` (`?id=2500` selects a plot by id, `?plot=B-12` by number, `?skip=roads,plots,parks` is a debugging aid).

Regenerate data: `python -I tools/make_data.py --preview preview.png` (needs `pip install shapely numpy matplotlib`).
Screenshot test: `python -I tools/shoot.py http://127.0.0.1:8000/map.html out.png --js "window.__map.select(2500)"` (needs `pip install playwright`).

## 3D map (`assets/map3d.js`)

- CesiumJS **1.119** from the Cesium CDN (`<script>` tag in `map.html`), World Terrain + World Imagery when a token is set, OpenStreetMap tiles + ellipsoid otherwise.
- `Map3D(elementId, { onPick, onHover, onStatus, layer, selectId, dataUrl, skip })` returns `{ setLayer, select, clearSelection, reset, zoomIn, zoomOut, flyToBlock, search, get, plots, ready, rendered, viewer }`.
- Layers: `cls` (development class), `stat` (plot status), `sat` (built / vacant). Colours match the legend in `map.html`.
- Plots are one batched `Primitive` of extruded polygons (per-instance colour, picking id `{plot: id}`); roads, parks and the boundary are ground primitives. Do not switch plots to entities: 6,000+ entities is too slow.
- Rings passed to Cesium must not repeat the closing point and must not contain consecutive duplicates (`toCart(ring, true)` handles it); otherwise the geometry worker throws "normalized result is not a number" and rendering stops.
- `onPick(props)` receives the clicked plot's GeoJSON properties (or `null` when clicking empty ground); `map.html` renders the side panel from them.

## Data format (`data/`, GeoJSON, EPSG:4326 / WGS84)

| File | Geometry | Source |
| --- | --- | --- |
| `boundary.geojson` | Polygon | OpenStreetMap way 287541676 (georeferenced) |
| `roads.geojson` | LineString, props `class` (main/arterial/residential), `width_m`, `name` | OpenStreetMap (georeferenced) |
| `blocks.geojson` | Polygon, props `block`, `kind`, `plot_size` | polygonised road network (approximate) |
| `parks.geojson` | Polygon, props `name`, `kind` (park/amenity) | generated (approximate) |
| `plots.geojson` | Polygon | generated inside blocks at official sizes (approximate, sample attributes) |

Plot properties: `id`, `plot_no` (e.g. `B-12`), `block`, `size` (5/10/20 Marla or Commercial), `type`, `status` (Available, Reserved, Sold, Unknown), `dev_class` (High, Medium, Low), `built`, `storeys`, `height` (m), `height_source` (`assumed`), `source`, `confidence`, `lat`, `lon`, `area_m2`, `accuracy` (`approximate` or `georeferenced`).

**Plot geometry and attributes are generated samples.** Real plot records and model output will replace them with the same file and property names; the map code should not need changes. Block letters A–F follow the official layout (A, B, C north-west of the main boulevard, F, E, D south-east) but the split points are approximate.

## Rules that come from the project documents

- When the proposal and the use case diagram disagree, **the use case diagram wins**.
- Actors: End User, Society Head, System Administrator. Secondary: AI/ML Model, Cesium Js.
- Forecast horizon is **5 years**, always labelled as a model estimate with uncertainty.
- Plot status comes from verified records only, never from satellite imagery alone, and is shown with its source and confidence.
- There is **no plot-comparison feature** (no use case for it).
- Heights are assumed (3.5 m per storey) until real data exists; label them as assumed.
